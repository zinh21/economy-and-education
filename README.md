## 📌 프로젝트 개요

한국의 사교육은 더 이상 단순한 학습 보조 수단이 아닙니다.
2024년 기준 연간 29조 원이 넘는 거대한 산업으로 성장했으며
학원, 인터넷 강좌, 입시 컨설팅 등 다양한 형태로 팽창하고 있습니다.

이 프로젝트는 다음 핵심 질문에 데이터로 답합니다.

- 사교육 시장은 얼마나, 어떻게 성장했는가?
- 사교육은 교육 격차를 얼마나 심화시키는가?
- 사교육 업계는 어떤 방식으로 수요를 창출하고 수익을 극대화하는가?

통계청 사교육비 조사 데이터(2016~2025, 10년치)를 Streamlit 기반
인터랙티브 보고서로 시각화하여 사교육 상업화의 실태를 분석합니다.

## 🚨 핵심 발견 요약

| 지표 | 수치 |
|------|------|
| 사교육비 총액 변화 | 2016년 18조 원 → 2024년 29조 원 (+61%) |
| 지역 격차 | 서울 = 읍면지역의 약 2배 |
| 성적 구간 참여율 격차 | 상위 10% 76.6% vs 하위 20% 55.7% = 21%p 차이 |
| 에듀테크 성장률 | 인터넷강좌 2016년 대비 2024년 217% 성장 |
| 과목 집중도 | 수학 + 영어 = 일반교과 사교육비의 약 70% |

## 🗂️ 페이지 구성

### 🔴 Page 1 · 문제의 심각성

사교육 상업화가 얼마나 심각한 사회문제인지 데이터로 증명합니다.

| 분석 항목 | 내용 |
|-----------|------|
| 사교육비 총액 추이 | 2016~2025년 연간 사교육비 변화 |
| 학교급별 구성 | 초·중·고 사교육비 비중 변화 |
| 지역별 격차 | 서울 vs 읍면지역 사교육비 배율 |
| 성적 구간별 참여율 | 상위 10% vs 하위 20% 참여율 격차 |
| 과목별 격차 | 국·영·수·사과·논술 성적 구간별 비교 |

### 🟠 Page 2 · 상업화 구조 분석

교육이 어떻게 돈벌이가 되는지 5가지 관점에서 분석합니다.

수학·영어가 전체 사교육비의 약 70%를 차지하는 과목 과점 구조,
학원보다 3배 빠르게 성장한 인터넷강좌 시장,
입시 스펙으로 편입된 체육·예술 사교육의 팽창,
성적 상위권 학생마저 참여율이 오르는 불안 마케팅의 실태,
그리고 불안 조성부터 플랫폼 구독화까지 이어지는
사교육 산업화 4단계 메커니즘을 데이터로 규명합니다.

## 💡 사교육 상업화 4단계 메커니즘

| 단계 | 전략 | 데이터 근거 |
|------|------|-------------|
| 1단계 불안 조성 | 안 하면 뒤처진다는 공포 마케팅 | 상위 10%도 참여율 꾸준히 상승 |
| 2단계 과목 과점화 | 수학·영어 중심 독과점 구조 | 두 과목이 전체의 약 70% 차지 |
| 3단계 프리미엄화 | 고가 입시 컨설팅 시장 창출 | 진로상담 2017년 신설 후 2024년 1007억 원 |
| 4단계 플랫폼 구독화 | 에듀테크 구독 모델 확산 | 인터넷강좌 217% 성장 |

## 🚀 실행 방법

1단계 저장소 클론

    git clone https://github.com/zinh21/economy-and-education.git
    cd economy-and-education

2단계 패키지 설치

    pip install -r requirements.txt

3단계 앱 실행

    streamlit run app.py

4단계 브라우저에서 확인

    http://localhost:8501
