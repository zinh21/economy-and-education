## 📌 프로젝트 개요

한국의 사교육은 더 이상 단순한 학습 보조 수단이 아닙니다.
2024년 기준 연간 **29조 원**이 넘는 거대한 산업으로 성장했으며,
학원, 인터넷 강좌, 입시 컨설팅 등 다양한 형태로 팽창하고 있습니다.

이 프로젝트는 다음 핵심 질문에 데이터로 답합니다.

- 사교육 시장은 얼마나, 어떻게 성장했는가?
- 사교육은 교육 격차를 얼마나 심화시키는가?
- 사교육 업계는 어떤 방식으로 수요를 창출하고 수익을 극대화하는가?

통계청 사교육비 조사 데이터(2016~2025, 10년치)를 Streamlit 기반
인터랙티브 보고서로 시각화하여 사교육 상업화의 실태를 분석합니다.

## 🚨 핵심 발견 요약

10년간 데이터 분석을 통해 발견한 주요 수치입니다.

사교육비 총액 변화

    2016년 약 18조 원 → 2024년 약 29조 원
    10년간 약 61% 증가

지역 격차

    서울 사교육비 = 읍면지역의 약 2배
    도시-농촌 간 교육 기회 불균형 고착화

성적 구간별 참여율 격차 (2024년)

    성적 상위 10% 참여율: 76.6%
    성적 하위 20% 참여율: 55.7%
    격차: 21%p

과목 집중도

    수학 + 영어 = 전체 일반교과 사교육비의 약 70%
    수학 사교육비: 2016년 5.4조 → 2024년 8.3조 (+53%)

에듀테크 성장

    유료 인터넷강좌: 2016년 대비 2024년 217% 성장
    방문학습지는 동기간 지속 하락 → 디지털 전환 가속

진로·진학 상담 신시장

    2017년 통계 신설 → 2024년 약 1,007억 원 규모
    상위 10% 참여율이 하위 20%의 약 3~4배

## 🗂️ 페이지 구성 및 상세 내용

### 🔴 Page 1 · 문제의 심각성

사교육 상업화가 얼마나 심각한 사회문제인지 데이터로 증명하는 파트입니다.

#### 핵심 수치 요약 (KPI)
페이지 최상단에 4가지 핵심 지표를 카드 형식으로 표시합니다.

    2024년 사교육비 총액 / 2016→2024 증가율 /
    성적 상하위 참여율 격차 / 서울 vs 읍면 사교육비 비율

#### 분석 1 · 사교육비 총액 10년 추이
2016년부터 2025년까지 전체 및 지역별(서울, 광역시, 중소도시, 읍면지역)
사교육비 총액 변화를 라인 차트로 시각화합니다.
코로나 팬데믹(2020) 충격과 2021년 이후 급반등 구간을 주석으로 표시합니다.

#### 분석 2 · 학교급별 사교육비 구성 변화
초등학교, 중학교, 고등학교별 사교육비를 누적 막대 차트와
2024년 기준 도넛 차트로 비교합니다.
초등 사교육비가 전체의 약 45%를 차지한다는 점을 부각합니다.

#### 분석 3 · 지역별 사교육비 격차
2016, 2019, 2022, 2024년 4개 시점에서 서울, 광역시, 중소도시, 읍면지역의
사교육비를 그룹 막대 차트로 비교하고, 서울/읍면 배율 추이를 별도 라인 차트로 표시합니다.

#### 분석 4 · 성적 구간별 사교육 참여율 격차
상위 10%, 11~30%, 31~60%, 61~80%, 하위 20%로 나뉜
5개 성적 구간의 참여율 추이를 라인 차트로 보여줍니다.
2016년과 2024년을 비교하는 레이더 차트도 제공합니다.

#### 분석 5 · 과목별 성적 구간 참여율 격차 (2024)
국어, 영어, 수학, 사회·과학, 논술 5개 과목에 대해
상위 10%와 하위 20%의 참여율 격차를 그룹 막대 차트와
인사이트 카드로 표시합니다.

### 🟠 Page 2 · 상업화 구조 분석

교육이 어떻게 돈벌이가 되는지, 상업화의 구체적 메커니즘을 분석하는 파트입니다.

#### 분석 1 · 과목별 사교육비 포트폴리오 변화
국어, 영어, 수학, 사회·과학, 논술, 예체능·취미교양 6개 영역의
사교육비 구성 비율을 100% 누적 면적 차트로, 절대 금액을 라인 차트로,
2024년 비중을 도넛 차트로 동시에 보여줍니다.

#### 분석 2 · 사교육 유형별 시장 구조 변화
학원수강, 개인과외, 그룹과외, 방문학습지, 유료인터넷강좌
5가지 유형의 시장 규모 변화를 누적 막대 차트로 시각화하고
유형별 성장률 KPI를 제공합니다.

#### 분석 3 · 학원 vs 에듀테크 성장 지수 비교
2016년을 기준(100)으로 학원수강과 유료인터넷강좌의
성장 지수를 동일 축에서 비교합니다.
코로나 팬데믹이 에듀테크 성장에 미친 영향을 시각적으로 보여줍니다.

#### 분석 4 · 예체능·취미교양 사교육 팽창
음악, 미술, 체육, 취미·교양 4개 영역의 사교육비 추이와
2016년 vs 2024년 비교를 통해 스펙화 담론에 따른
사교육 수요 다각화 전략을 분석합니다.

#### 분석 5 · 불안 마케팅의 데이터 근거
성적 상위 10% 학생들의 사교육 참여율 추이를 과목별로 분석하여
이미 잘하는 학생들도 사교육을 더 많이 받는 구조를 데이터로 증명합니다.
과목별 × 연도별 히트맵도 제공합니다.

#### 분석 6 · 사교육 상업화 3가지 패턴 카드
불안 마케팅, 프리미엄화·고가화, 디지털 구독화
3가지 상업화 패턴을 카드 형식으로 정리하고
각 패턴의 데이터 근거를 함께 제시합니다.

#### 분석 7 · 신(新)사교육 영역 — 진로·진학 상담 상업화
2017년 통계에 처음 등장한 진로·진학 상담 사교육 시장의 성장과
성적 구간별 참여율 격차를 분석합니다.
상위 10% 참여율이 하위 20%의 약 3~4배에 달한다는 점을 부각합니다.

#### 분석 8 · 아날로그→디지털 전환
방문학습지와 유료인터넷강좌의 시장 규모 추이를 하나의 차트에서 비교하여
두 시장이 역전되는 시점과 디지털 사교육 시대로의 전환을 시각화합니다.

#### 분석 9 · 사교육 산업화 종합 요약
4단계 메커니즘(불안 조성 → 과목 과점화 → 프리미엄화 → 플랫폼 구독화)을
단계별 카드로 정리하고, 전체 사교육비 총액과 유형별 비중 변화를
2개 패널 콤보 차트로 종합합니다.

## 🚀 실행 방법

로컬 환경에서 실행하는 순서입니다.

1단계 저장소 클론

    git clone https://github.com/zinh21/economy-and-education.git
    cd economy-and-education

2단계 가상환경 생성 (선택사항)

    python -m venv venv
    source venv/bin/activate
    (Windows의 경우: venv\Scripts\activate)

3단계 패키지 설치

    pip install -r requirements.txt

4단계 앱 실행

    streamlit run app.py

5단계 브라우저에서 확인

    http://localhost:8501
