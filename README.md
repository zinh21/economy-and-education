# 📚 사교육 상업화 분석 보고서

> 데이터로 보는 한국 사교육 산업화의 실태 — 당곡고등학교 프로젝트

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://economy-and-education.streamlit.app)

---

## 📌 프로젝트 소개

한국의 사교육은 단순한 교육 보조 수단을 넘어 **거대한 산업**으로 성장했습니다.
이 프로젝트는 통계청 사교육비 조사 데이터(2016~2025)를 기반으로
사교육 상업화의 **실태**와 **구조적 메커니즘**을 인터랙티브 보고서 형식으로 시각화합니다.

## 🔍 핵심 발견

| 지표 | 수치 |
|------|------|
| 사교육비 총액 변화 | 2016년 18조 원 → 2024년 29조 원 (+61%) |
| 지역 격차 | 서울 = 읍면지역의 약 2배 |
| 성적 구간 참여율 격차 | 상위 10% 76.6% vs 하위 20% 55.7% = 21%p 차이 |
| 에듀테크 성장률 | 인터넷강좌 2016년 대비 2024년 217% 성장 |
| 과목 집중도 | 수학 + 영어 = 일반교과 사교육비의 약 70% |

## 💡 사교육 상업화 4단계 메커니즘

| 단계 | 전략 | 데이터 근거 |
|------|------|-------------|
| 1단계 불안 조성 | 안 하면 뒤처진다는 공포 마케팅 | 상위 10%도 참여율 꾸준히 상승 |
| 2단계 과목 과점화 | 수학·영어 중심 독과점 구조 | 두 과목이 전체의 70% 차지 |
| 3단계 프리미엄화 | 고가 입시 컨설팅 시장 창출 | 진로상담 2017년 신설 후 2024년 1007억 원 |
| 4단계 플랫폼 구독화 | 에듀테크 구독 모델 확산 | 인터넷강좌 217% 성장 |

## 🚀 실행 방법

로컬 실행 순서입니다.

1단계 저장소 클론

    git clone https://github.com/zinh21/economy-and-education.git
    cd economy-and-education

2단계 패키지 설치

    pip install -r requirements.txt

3단계 앱 실행

    streamlit run app.py
